# Changelog

## 2.1.0 — Nimble Jackal

First public source release of the Player History admin client.

- Dashboard, global map, player timelines, compare view, and item tracking
- Map replay with Quiet / Forensic / Everything signal modes
- Live WebSocket updates from Player History Server
- Optional CFTools integration UI
- Browser SPA (`web/`) and portable Windows `.exe` (`build-desktop.bat`)
